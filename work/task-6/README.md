# Task 6: Competitor Comparison

## Objective

Compare all four companies using the engineered features within a shared comparison framework, surfacing similarities, differences and strategic gaps.

## What is submitted

**Each member (in their own folder)**

1. Their company's comparison tables and visuals
2. A short explanation of how their company compares

## Rules for this task

- Comparisons are normalised. Never raw counts across companies of different sizes.
- The same taxonomy and the same matcher for everyone: `scripts/skill_matcher.py`.
- State the basis. Titles and descriptions are not interchangeable.

## Open team decisions raised by this task

1. **The four-way comparison is not currently valid.** NVIDIA's apparent skill-richness comes from
   the 34 skills added to the taxonomy in Task 4: on the pre-extension taxonomy NVIDIA scores 21.2%
   and Google 22.3%. **Every member must extend the taxonomy for their own company, then everyone
   re-runs Task 4.** This is the highest-value action left in the project.
2. **Titles or descriptions, decided once.** Microsoft yields 0.08 skills per posting from titles
   and 6.84 from descriptions, a factor of 85.
3. **No cross-company time series is possible.** Google has no dates, Microsoft's column is empty,
   and Meta's window is 2024 against NVIDIA's 2026.

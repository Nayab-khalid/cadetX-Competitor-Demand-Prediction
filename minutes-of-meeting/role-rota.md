# Rotating Weekly Roles

Four roles rotate every week so that each member performs each role during the project.

| Role | Responsibility |
|---|---|
| Scrum Leader | Organises and runs the weekly meeting, coordinates task distribution, is the main point of contact, and ensures the week's work is uploaded to this repository |
| Data Quality Lead | Ensures the datasets are clean, consistent and validated across all four companies |
| Documentation Lead | Maintains the documentation, meeting minutes and project notes |
| Technical Lead | Oversees code structure and technical decisions, and assists with implementation problems |
